# Logic Circuits Laboratory - Reports and Design Files

This repository contains the lab reports and the circuit design files for the Logic Design Laboratory course offered in semester 1404-3.

در این ریپازیتوری، گزارش‌های آزمایش و فایل مدارهای طراحی‌شده‌ی آنها، مربوط به درس آزمایشگاه مدار منطقی ارائه‌شده در ترم ۱۴۰۴-۳ آمده است.
